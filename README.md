# 灵动岛 for Windows

轻量的 Windows 灵动岛。Rust + Win32 + Direct2D + DirectComposition，无运行时、无 WebView。

## 运行

```bash
cargo run --release
```

- 鼠标悬停（或点击）展开，移开收回
- 右键 → 退出
- 有全屏应用（全屏视频、游戏、演示）时自动隐藏
- 调试：`ISLAND_ALWAYS_SHOW=1` 全屏时也显示；`ISLAND_DEBUG_DROP=1`（仅调试版）启动即显示放置区

## 已有功能

| 形态 | 触发 |
|---|---|
| 空闲药丸 | 默认 |
| 音乐紧凑态（封面 + 频谱） | 有媒体在播放，暂停 30 秒后收起 |
| 切歌提示 | 切换曲目时显示 2.8 秒 |
| 充电提示 | 插上电源 |
| 展开·媒体（封面、标题、进度、上一首/播放/下一首） | 悬停，且有媒体会话 |
| 展开·仪表盘（时间、日期、电量） | 悬停，且没有媒体 |
| 放置区「松手放进暂存区」 | 拖着文件移到屏幕顶部中间 |
| 暂存区（展开态底部一行，最多 5 个） | 暂存区里有文件 |

### 文件暂存区

- 把文件拖到屏幕顶部中间，岛会变成放置区，松手即暂存（只记路径，不复制文件）
- 展开后：拖动文件可以拖到资源管理器、聊天窗口、网页上传框；单击用默认程序打开；悬停后点右上角 × 移除
- 收起时药丸上显示暂存数量；右键菜单可以「清空暂存区」
- 文件被移走或删除后自动从暂存区去掉；列表存在 `%APPDATA%\WinDynamicIsland\shelf.txt`，重启后保留

媒体通过系统媒体传输控件（SMTC）获取，支持 Spotify、浏览器、网易云等接入了系统媒体控制的播放器。

## 结构

| 文件 | 职责 |
|---|---|
| `src/main.rs` | 窗口、消息循环、点击穿透、全屏让位 |
| `src/island.rs` | 状态机、弹簧形变、各形态的绘制和命中测试 |
| `src/render.rs` | D3D11 / D2D / DirectComposition 渲染封装 |
| `src/media.rs` | SMTC 媒体线程（事件驱动）、封面解码、取色 |
| `src/shelf.rs` | 暂存区：文件列表、缩略图、持久化、Shell 数据对象 |
| `src/dragdrop.rs` | OLE 放置目标 |
| `examples/drag_source.rs` | 测试工具：从独立进程做一次真实的文件拖拽 |
| `src/spring.rs` | 阻尼弹簧 |
| `src/system.rs` | 电池、全屏检测、时钟 |

## 资源占用（2560×1440 @150%，实测）

- 可执行文件约 225 KB
- 空闲 CPU 约 0.4%（单核）
- 内存约 60 MB，主要是 D3D 显卡驱动的固定开销
