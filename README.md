# 灵动岛 for Windows

轻量的 Windows 灵动岛。Rust + Win32 + Direct2D + DirectComposition，无运行时、无 WebView。

## 运行

```bash
cargo run --release
```

- 鼠标悬停（或点击）展开，移开收回；有音乐时展开态用滚轮（或点顶部小圆点）在「媒体 / 仪表盘」间切换
- 右键岛或托盘图标打开菜单：显示歌词、音量/亮度提示、全屏时隐藏、空闲时收成细条、显示在哪个显示器、开机自启、退出
- 有全屏应用（全屏视频、游戏、演示）时自动隐藏（可关）
- 设置存在 `%APPDATA%\WinDynamicIsland\settings.ini`；开机自启写在 `HKCU\...\CurrentVersion\Run`
- 调试：`ISLAND_ALWAYS_SHOW=1` 全屏时也显示。仅调试版：`ISLAND_DEBUG_DROP=1` 启动即显示放置区；
  `ISLAND_DEBUG=level|bright|timer|dash|dash0|media|media_x|trans|privacy|dots|device|lowbatt|slim` 直接进入某个形态；`ISLAND_TRACE=1` 每秒打印循环和出帧次数

## 已有功能

| 形态 | 触发 |
|---|---|
| 空闲药丸 | 默认；菜单里可改成贴顶细条，少挡浏览器标签页（有暂存文件、隐私指示点时仍是药丸） |
| 音乐紧凑态（封面 + 频谱；有歌词时加宽显示当前一句） | 有媒体在播放，暂停 30 秒后收起 |
| 切歌提示 | 切换曲目时显示 2.8 秒 |
| 充电提示 | 插上电源 |
| 电量不足 | 没插电时电量降到 20%、10% |
| 输出设备 | 默认输出设备换了（插耳机、连蓝牙耳机），显示设备名和音量 |
| 麦克风 / 摄像头提示 | 有应用开始用麦克风（橙点）或摄像头（绿点）；使用期间紧凑态一直显示指示点 |
| 音量 / 亮度条 | 按音量键、调笔记本屏幕亮度，显示 1.6 秒 |
| 计时器（橙色圆环 + 倒计时） | 计时中且没有音乐；有音乐时倒计时显示在音乐紧凑态右侧 |
| 计时结束提示 | 计时到点，提示音 + 显示 6 秒 |
| 展开·媒体（封面、标题、歌词及翻译、可拖动进度条、上一首/播放/下一首） | 悬停，且有媒体会话 |
| 展开·仪表盘（时间、日期、电量、计时器 1/5/15/25 分钟） | 悬停，且没有媒体；有媒体时滚轮切过来 |
| 放置区「松手放进暂存区」 | 拖着文件移到屏幕顶部中间 |
| 暂存区（展开态底部一行，最多 5 个） | 暂存区里有文件 |

### 文件暂存区

- 把文件拖到屏幕顶部中间，岛会变成放置区，松手即暂存（只记路径，不复制文件）
- 展开后：拖动文件可以拖到资源管理器、聊天窗口、网页上传框；单击用默认程序打开；悬停后点右上角 × 移除
- 收起时药丸上显示暂存数量；右键菜单可以「清空暂存区」
- 文件被移走或删除后自动从暂存区去掉；列表存在 `%APPDATA%\WinDynamicIsland\shelf.txt`，重启后保留

媒体通过系统媒体传输控件（SMTC）获取，支持 Spotify、浏览器、网易云等接入了系统媒体控制的播放器。

### 进度和歌词

- 展开态的进度条可以点击或按住拖动跳转；播放器不支持跳转（SMTC 没开放）时进度条只显示不响应
- 歌词：切歌时用「歌名 + 歌手 + 时长」在线查找，中文歌先查网易云、其它先查 LRCLIB，找到后缓存到
  `%APPDATA%\WinDynamicIsland\lyrics\`，同一首歌不再联网。网易云带翻译的外文歌，展开态在原文下面多一行翻译。会把歌名和歌手发给这两个服务，不想联网可以在菜单里关掉「显示歌词」
### 音量 / 亮度

- 开着「音量 / 亮度提示」时，岛会接管键盘上的音量加、减、静音键（每次 2%，和系统一致），系统自带的音量浮窗不再出现；
  岛因全屏应用隐藏时按键交还给系统，照常显示系统浮窗
- 其它方式改音量（任务栏音量滑块、应用里调）也会显示音量条
- 亮度只支持笔记本内屏（外接显示器走 DDC/CI，系统不发通知）；系统亮度浮窗由固件/驱动触发，接管不了，会同时出现。
  插拔电源、屏幕空闲变暗和恢复时系统自动调的亮度不弹；开着「自动调节亮度」的话，光线变化时可能会弹

## 结构

| 文件 | 职责 |
|---|---|
| `src/main.rs` | 窗口、消息循环、点击穿透、全屏让位 |
| `src/island.rs` | 状态机、弹簧形变、各形态的绘制和命中测试 |
| `src/render.rs` | D3D11 / D2D / DirectComposition 渲染封装 |
| `src/media.rs` | SMTC 媒体线程（事件驱动）、封面解码、取色、跳转进度 |
| `src/lyrics.rs` | 歌词查找（网易云 / LRCLIB）、LRC 解析、翻译合并、缓存 |
| `src/audio.rs` | CoreAudio 音量回调、默认输出设备切换、代替系统调音量 |
| `src/volkeys.rs` | 低级键盘钩子，接管音量键 |
| `src/settings.rs` | 设置文件、开机自启 |
| `src/tray.rs` | 托盘图标（代码绘制） |
| `src/privacy.rs` | 麦克风 / 摄像头占用检测：摄像头用 Media Foundation 传感器活动监视器，麦克风查录音设备上的活动音频会话 |
| `assets/` | 程序图标及其生成脚本（`python assets/make_icon.py`），由 `build.rs` 编进 exe |
| `src/shelf.rs` | 暂存区：文件列表、缩略图、持久化、Shell 数据对象 |
| `src/dragdrop.rs` | OLE 放置目标 |
| `examples/drag_source.rs` | 测试工具：从独立进程做一次真实的文件拖拽 |
| `examples/vol_key.rs` | 测试工具：模拟按一次音量键，2.5 秒后恢复原音量 |
| `examples/vol_poke.rs` | 测试工具：切换两次静音，触发音量变化通知 |
| `examples/mic_probe.rs` | 测试工具：打开默认麦克风几秒（数据直接丢弃），检查橙色指示点 |
| `src/spring.rs` | 阻尼弹簧 |
| `src/system.rs` | 电池、全屏检测、显示器列表、时钟 |

## 资源占用（2560×1440 @150%，实测）

- 可执行文件约 510 KB（WinRT HTTP / JSON、CoreAudio 绑定和图标占了大头）
- 空闲 CPU 约 0.2%–2.8%（单核），随系统负载波动，和上一版同时测量基本持平
- 内存约 60 MB，主要是 D3D 显卡驱动的固定开销
