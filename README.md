# 灵动岛 for Windows

轻量的 Windows 灵动岛。Rust + Win32 + Direct2D + DirectComposition，无运行时、无 WebView，单个 exe 约 700 KB。

<p align="center"><img src="docs/screenshots/trans.png" width="620" alt="展开的播放卡片：封面、歌名、双语歌词、进度条和播放控制"></p>

## 为什么选它

- **小而轻**：一个约 700 KB 的 exe，不用安装，不依赖 .NET、Electron、WebView 或 VC++ 运行库；
  空闲时几乎不占 CPU——媒体、音量、设备都是系统事件驱动，画面没变化就不重绘
- **跟手、顺滑**：GPU 合成（DirectComposition）+ 弹簧动画，帧和系统合成节拍对齐，高刷新率屏幕上也不撕裂；
  按显示器缩放（Per-Monitor DPI v2）清晰渲染，多显示器可选显示在哪块屏上
- **不打扰**：不抢焦点，岛以外的地方点击直接穿透到下面的窗口；全屏看视频、玩游戏时自动让位；可收成贴顶细条，少挡浏览器标签页
- **像 iPhone 的灵动岛**：两个播放器时分出小圆泡、麦克风 / 摄像头指示点、充电 / 低电量 / 耳机连接提示、计时器，
  音量键提示直接替代系统音量浮窗
- **为中文用户做的**：歌词优先查网易云并显示中文翻译，天气用国内访问快的服务，便签输入支持中文输入法
- **一站式**：音乐控制、歌词、拖动进度、文件暂存区、天气、电量和剩余时间、计时器、便签都在一个岛上
- **尊重隐私**：没有账号、没有统计上报；只有歌词和天气会联网，只发必要的信息，都能在菜单里关掉；数据都存在本机
- **开源**：MIT 许可，代码约 6000 行，可以自己审查、修改、编译

## 下载使用

1. 到本仓库的 [Releases](../../releases) 页面下载最新的 `island.exe`（或 `island-windows-x64.zip`）
2. 放到任意文件夹，双击运行。不需要安装，也不需要装任何运行库；岛出现在屏幕顶部中间，托盘里有它的图标
3. 想开机自动启动：右键岛或托盘图标 →「开机自启」。卸载：退出后删掉 exe，再删掉 `%APPDATA%\WinDynamicIsland` 文件夹

**系统要求**：Windows 11 或较新的 Windows 10（64 位）。目前只在 Windows 11 上实测过。

**第一次运行时可能遇到**

- 「Windows 已保护你的电脑」：exe 没有做代码签名，点「更多信息 → 仍要运行」即可
- 杀毒软件提示：岛接管音量键用的是系统的低级键盘钩子（只处理音量加、减、静音三个键，不记录其它按键），
  个别杀毒软件会因此报可疑。不放心可以自己从源码编译，或在菜单里关掉「音量 / 亮度提示」（关掉后不再接管按键）
- 联网：只有歌词（发送歌名、歌手）和天气（发送约 10 公里精度的位置或手动设置的城市）会联网，都可以在菜单里关掉

## 从源码编译

需要 [Rust](https://rustup.rs/) 1.88 或更新（MSVC 工具链）：

```bash
cargo run --release
```

编译出的程序在 `target/release/island.exe`。C 运行库是静态链接的（见 `.cargo/config.toml`），拷到别的电脑上也能直接运行。
推送到 GitHub 后，`.github/workflows/build.yml` 会自动检查、测试、编译；推送 `v` 开头的标签（如 `v0.1.0`）时自动把 exe 发布到 Releases。

## 使用

- 鼠标悬停（或点击）展开，移开收回；展开态用滚轮（或点顶部小圆点）在「媒体 / 仪表盘 / 便签」间翻页（没有音乐时没有媒体页）；再次展开回到上次看的那页
- 能点的地方指上去会显示手形并浮出底色，按下时轻轻一缩；点封面或歌名把播放器切到前台，点时钟打开「时钟」，点电量打开电池设置
- 右键岛或托盘图标打开菜单：显示歌词、音量/亮度提示、全屏时隐藏、空闲时收成细条、显示天气、显示在哪个显示器、开机自启、退出
- 有全屏应用（全屏视频、游戏、演示）时自动隐藏（可关）
- 设置存在 `%APPDATA%\WinDynamicIsland\settings.ini`；开机自启写在 `HKCU\...\CurrentVersion\Run`
- 调试：`ISLAND_ALWAYS_SHOW=1` 全屏时也显示。仅调试版：`ISLAND_DEBUG_DROP=1` 启动即显示放置区；
  `ISLAND_DEBUG=level|bright|timer|dash|dash0|media|media_x|trans|privacy|dots|device|connected|lowbatt|slim|notes|weather|split|split_x` 直接进入某个形态；`ISLAND_TRACE=1` 每秒打印循环和出帧次数

## 已有功能

| 形态 | 触发 |
|---|---|
| 空闲药丸 | 默认；菜单里可改成贴顶细条，少挡浏览器标签页（有暂存文件、隐私指示点时仍是药丸） |
| 音乐紧凑态（封面 + 频谱；有歌词时加宽显示当前一句） | 有媒体在播放，暂停 30 秒后收起 |
| 切歌提示 | 切换曲目时显示 2.8 秒 |
| 充电提示 | 插上电源 |
| 电量不足 | 没插电时电量降到 20%、10% |
| 输出设备 | 默认输出设备换了（插耳机、连蓝牙耳机）或新连上一个输出设备，显示设备名和音量 / 「已连接」；蓝牙耳机上报了电量时显示电量 |
| 两个播放器（像 iPhone 那样分成两块） | 另一个播放器也在播放时，岛右边分出一个小圆泡（它的封面）；点小圆泡两边互换 |
| 麦克风 / 摄像头提示 | 有应用开始用麦克风（橙点）或摄像头（绿点）；使用期间紧凑态一直显示指示点 |
| 音量 / 亮度条 | 按音量键、调笔记本屏幕亮度，显示 1.6 秒 |
| 计时器（橙色圆环 + 倒计时） | 计时中且没有音乐；有音乐时倒计时显示在音乐紧凑态右侧 |
| 计时结束提示 | 计时到点，提示音 + 显示 6 秒 |
| 展开·媒体（封面、标题、歌词及翻译、可拖动进度条、上一首/播放/下一首；有第二个播放器时右上角「切到 xx」） | 悬停，且有媒体会话 |
| 展开·仪表盘（时间、日期、天气、电量和剩余使用时间、计时器 1/5/15/25 分钟） | 悬停，且没有媒体；有媒体时滚轮切过来 |
| 展开·便签（条数不限，一次显示 5 条） | 滚轮翻到最后一页 |
| 放置区「松手放进暂存区」 | 拖着文件移到屏幕顶部中间 |
| 暂存区（展开态底部一行，最多 5 个） | 暂存区里有文件 |

### 文件暂存区

- 把文件拖到屏幕顶部中间，岛会变成放置区，松手即暂存（只记路径，不复制文件）
- 展开后：拖动文件可以拖到资源管理器、聊天窗口、网页上传框；单击用默认程序打开；悬停后点右上角 × 移除
- 收起时药丸上显示暂存数量；右键菜单可以「清空暂存区」
- 文件被移走或删除后自动从暂存区去掉；列表存在 `%APPDATA%\WinDynamicIsland\shelf.txt`，重启后保留

媒体通过系统媒体传输控件（SMTC）获取，支持 Spotify、浏览器、网易云等接入了系统媒体控制的播放器。
同时有几个播放器时，主位跟随系统的「当前会话」；点小圆泡选中另一个后固定显示它，直到别的播放器新开始播放（和 iPhone「最新的活动在主位」一致）。

### 便签

- 记一些随手的想法：便签页点右上角「+」，在出现的输入框里打字（支持中文输入法），回车保存、Esc 取消，点别处也会保存
- 点一条复制到剪贴板；悬停后点右边的 × 删除；条数不限，一次显示 5 条，多了用滚轮在便签里上下翻（翻到顶再往上滚回到上一页）；
  每条最多 200 字，一行放不下时显示省略号，复制出来是完整的
- 存在 `%APPDATA%\WinDynamicIsland\notes.txt`，一行一条，也可以直接用记事本改

### 天气、电量

- 天气用 Windows 定位拿到大概位置，先查 wttr.in（国内访问快）、不通再查 Open-Meteo，每 30 分钟更新；
  只发送保留一位小数的经纬度（约 10 公里精度）。需要在「设置 → 隐私和安全性 → 位置」里打开定位服务和
  「允许桌面应用访问你的位置」，并且「地理位置服务」（Geolocation Service，lfsvc）没有被禁用——
  有些优化工具会把它禁掉，这时设置里的开关打开了也没用
- 系统定位用不了时，仪表盘上显示「定位不可用，点这里设置城市」，输入城市名（如「上海」）后按城市名查；
  之后点天气可以改城市，清空就不再按城市查。城市存在 settings.ini 的 `weather_city`。不想联网可以在菜单里关掉「显示天气」
- 不用 IP 估算位置：开着代理 / VPN 时会估到国外
- 没插电时仪表盘显示系统估算的剩余使用时间（刚拔电时系统还没估算出来，会过一会儿才出现）
- 蓝牙耳机电量来自耳机通过免提协议上报给 Windows 的值（和「设置 → 蓝牙和设备」里显示的一样）；不上报电量的耳机不显示

### 进度和歌词

- 展开态的进度条可以点击或按住拖动跳转；播放器不支持跳转（SMTC 没开放）时进度条只显示不响应
- 点展开态的歌词，从这一句开头重听。播放器没有真的跳过去（比如 Spotify 在手机上播、电脑端只是遥控）时，1.5 秒内退回实际进度
- 歌词：切歌时用「歌名 + 歌手 + 时长」在线查找，中文歌先查网易云、其它先查 LRCLIB，找到后缓存到
  `%APPDATA%\WinDynamicIsland\lyrics\`，同一首歌不再联网。网易云带翻译的外文歌，展开态在原文下面多一行翻译。会把歌名和歌手发给这两个服务，不想联网可以在菜单里关掉「显示歌词」
### 音量 / 亮度

- 开着「音量 / 亮度提示」时，岛会接管键盘上的音量加、减、静音键（每次 2%，和系统一致），系统自带的音量浮窗不再出现；
  岛因全屏应用隐藏时按键交还给系统，照常显示系统浮窗
- 其它方式改音量（任务栏音量滑块、应用里调）也会显示音量条
- 亮度只支持笔记本内屏（外接显示器走 DDC/CI，系统不发通知）；系统亮度浮窗由固件/驱动触发，接管不了，会同时出现。
  插拔电源、屏幕空闲变暗和恢复时系统自动调的亮度不弹；开着「自动调节亮度」的话，光线变化时可能会弹

## 结构

| 文件 | 职责 |
|---|---|
| `src/main.rs` | 窗口、消息循环、点击穿透、全屏让位 |
| `src/island.rs` | 状态机、弹簧形变、各形态的绘制和命中测试 |
| `src/render.rs` | D3D11 / D2D / DirectComposition 渲染封装 |
| `src/media.rs` | SMTC 媒体线程（事件驱动）、封面解码、取色、跳转进度 |
| `src/lyrics.rs` | 歌词查找（网易云 / LRCLIB）、LRC 解析、翻译合并、缓存 |
| `src/audio.rs` | CoreAudio 音量回调、默认输出设备切换、新设备连上、代替系统调音量 |
| `src/headset.rs` | 蓝牙耳机电量：按容器 id 找到蓝牙设备节点读电量属性 |
| `src/weather.rs` | Windows 定位 + wttr.in / Open-Meteo 天气 |
| `src/notes.rs` | 便签的存取、复制到剪贴板 |
| `src/noteinput.rs` | 岛上的输入框：新建便签、设置天气城市（系统 EDIT 控件，支持输入法） |
| `src/volkeys.rs` | 低级键盘钩子，接管音量键 |
| `src/settings.rs` | 设置文件、开机自启 |
| `src/tray.rs` | 托盘图标（代码绘制） |
| `src/privacy.rs` | 麦克风 / 摄像头占用检测：摄像头用 Media Foundation 传感器活动监视器，麦克风查录音设备上的活动音频会话 |
| `assets/` | 程序图标及其生成脚本（`python assets/make_icon.py`），由 `build.rs` 编进 exe |
| `src/shelf.rs` | 暂存区：文件列表、缩略图、持久化、Shell 数据对象 |
| `src/dragdrop.rs` | OLE 放置目标 |
| `examples/drag_source.rs` | 测试工具：从独立进程做一次真实的文件拖拽 |
| `examples/vol_key.rs` | 测试工具：模拟按一次音量键，2.5 秒后恢复原音量 |
| `examples/vol_poke.rs` | 测试工具：切换两次静音，触发音量变化通知 |
| `examples/mic_probe.rs` | 测试工具：打开默认麦克风几秒（数据直接丢弃），检查橙色指示点 |
| `examples/audio_devices.rs` | 测试工具：列出启用的播放设备，标出默认设备 |
| `examples/geo_probe.rs` | 测试工具：检查 Windows 定位每一步的结果（不联网、不打印坐标） |
| `src/spring.rs` | 阻尼弹簧 |
| `src/system.rs` | 电池、全屏检测、显示器列表、时钟 |

## 资源占用（2560×1440 @150%，实测）

- 可执行文件约 700 KB（含静态链接的 C 运行库；WinRT HTTP / JSON、CoreAudio 绑定和图标占了大头）
- 空闲 CPU 约 0.2%–2.8%（单核），随系统负载波动，和上一版同时测量基本持平
- 内存约 60 MB，主要是 D3D 显卡驱动的固定开销
